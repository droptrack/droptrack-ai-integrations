# Security policy

## Reporting a vulnerability

Please report security issues privately through [DropTrack Support](https://droptrack.freshdesk.com/support/home) or by emailing support@droptrack.com.

Do not open a public issue for a suspected vulnerability. Include only the minimum information needed to reproduce the issue, and do not send access tokens, passwords, customer exports, or unrelated personal data.

## Authentication and data access

The DropTrack MCP server uses OAuth. Access is limited to the companies, data, and permissions available to the signed-in DropTrack account. Tokens are handled by the connecting client and should never be committed to this repository.
